## Кот в колодце

В папке [`well/`](well/) лежит браузерный рогалик «Кот в колодце»: десять глубин колодца, монстры, зелья, три героя и Древний Пёс, который стережёт кота Барсика.

Чтобы поиграть, откройте `well/dist/index.html` в браузере. Подробности — в [`well/README.md`](well/README.md).
